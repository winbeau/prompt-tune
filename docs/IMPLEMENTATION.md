# 当前实现与验证

## 当前交付

Electron 44 + React 19 + TypeScript 7，依赖版本由 lockfile 固定。使用 Electron 自带 Node 的 `node:sqlite`，无需额外 SQLite 原生模块重建。

- `src/main/index.ts`：悬浮窗、设置窗、托盘、快捷键、受限 IPC、导入导出。
- `src/main/models.ts`：自研协议执行与模型发现；Chat Completions / Responses / Messages，SSE、取消、超时、有限重试和 usage。
- `src/main/service.ts`：两种模式、独立任务绑定、结果校验、后台队列和每日总结调用限额。
- `src/main/storage.ts`：SQLite、凭据加密、历史、持久批次、证据去重与撤回。
- `src/main/prompts.ts`：独立翻译/微调模板，代码、URL 和占位符保护，证据约束。
- `src/renderer/src/`：双语界面、模型管理、编辑器、历史与表达习惯。

模型管理从 Pi 学习职责划分，未依赖 Pi SDK 或复制 Pi 源码。DeepSeek 填 key 后自动发现模型并沿用默认任务绑定。三种任务可各选一个供应商/模型。

Translate / Tune 每次只发送当前系统提示词与当前原文，三种协议均不追加历史、旧输出、习惯总结或会话标识。原文中的指令视为待编辑数据；模式切换与输入变化清空上一轮输出。

Tune 提示词版本为 1.1.0，以自然、地道的英文为目标，允许对生硬的词组或分句做必要改写，保留约束、语气和相近长度。大小写、空白和句尾句号静默修正；应用层再次过滤，避免模型返回的排版修改进入 edits 或习惯统计。SQLite user_version 2 会清理旧历史中的排版修改与关联证据，保留原文、输出及其他设置。

模型列表缓存持久保存；启动时仅刷新超过 24 小时的已配置供应商，用户也可手动刷新。失败保留旧列表；失踪模型保留并提示，手动配置、收藏和启用状态保留。DeepSeek 默认模型失效时选用发现的可用文本模型。OpenCode endpoint 由官方目录生成，未知协议需用户指定。

连接检查使用模型列表接口，不代表所有模型都已完成真实生成测试。不支持 `/models` 的第三方服务可手动配置模型并直接生成。

总结默认每 10 个成功保存的独立轮次建批。重试不增加独立轮次，英文可信纠错才构成错误证据；中文翻译与风格建议不计入。删除、否认纠正或重新生成使旧批次失效；后台返回时再次验证证据。前台请求取消在途总结并优先执行；重启恢复任务。

## 紧凑桌面界面

默认约 480 × 337 px；主窗口仅五行，输入和输出均为三行起步，随内容和字号平滑增高，超过屏幕高度时滚动。Return 提交，Shift+Return 换行，组合输入不提交。模式开关、运行按钮加载、流式光标与复制状态均有反馈。配色 system/light/black 跨窗口同步并持久化，默认跟随系统。Tune 为低饱和浅绿，Translate 为雾蓝；历史胶囊与主窗口使用相同颜色语义。设置窗默认为 740 × 620 px，Tab 增加内边距，精简重复文字和留白。macOS 仅显示关闭、最小化两个窗口控制；禁用全屏与最大化。主窗口使用普通 NSWindow 加浮动置顶层，避免 panel 的非激活行为。

文字默认 16px，设置提供 12–24px 滑杆、加减及重置。所有窗口的文字同步调整，主窗口宽度不随字号放大；文本测量使用实际行高，保证三行起步。字号通过 Zod 校验并保存在 SQLite，旧设置缺失字段时升级为 16px。`⌘+` / `⌘=` 放大、`⌘−` 缩小、`⌘0` 恢复默认；Windows 使用 Ctrl。原生菜单、原生输入事件和页面键盘路径共用同一持久化设置。

文本测量镜像使用与可见文本一致的宽度和内边距，保留末尾空行，流式光标也参与测量。输入和输出框从三行平滑增高，不设单框高度上限；原生窗口按动画帧跟随内容尺寸，计入窗口框架与内容区的高度差，达到屏幕可用高度后滚动。纠正卡片使用浅绿胶囊、短语对比与右上角否认按钮。

模式切换后焦点回到输入框；开关获得键盘焦点时 Return 仍提交当前模式，Space 切换模式。主题更新在绘制前同时应用整套配色，临时关闭颜色渐变，保留尺寸和位移动效，避免深色文字与浅色背景混用。两种模式按钮、纠正卡片、选中 Tab 与辅助文字均检查主题切换中的对比度。浮窗关闭后台帧节流，内容 ResizeObserver 直接同步原生窗口高度，避免流式显示或完成时的 操作按钮出现后漏增高。

## 验证

核心自动化测试包括：

- 三种协议请求与非流式解析；分段 UTF-8 / CRLF SSE；截断、未完成、取消；认证错误信息不含服务端原文或 key。
- 结果 JSON、受保护代码/占位符、改动来源、两种模式和双语键覆盖。
- 第 9/10/20 轮建批、同轮重试、翻译证据排除、证据去重/撤回、在途删除、重启恢复、关闭总结与加密持久化。

macOS 实际 Electron 窗口测试通过本地模拟 API 验证：

- 可见、默认置顶、可调整窗口大小、禁用全屏/最大化。
- `⌘,` 设置；`⌘W` 关闭设置与隐藏悬浮窗；`⌘Q` 退出；`Return` 提交、`Shift+Return` 换行。
- DeepSeek key 保存、自动发现、默认任务绑定、输入清空、密钥不出现在返回状态或磁盘明文中。
- CN→EN 和 EN→EN、只复制英文结果、中英文即时切换、历史列表和具体来源记录。
- 10 轮混合输入只调用一次后台总结，9 条英文纠错被统计，1 条中文翻译不算英文错误。
- 重启恢复设置、凭据、历史和证据，无渲染异常。
- 字号 12/16/24px、双窗口即时同步、快捷键、边界禁用与重启保存；最窄 440px 面板下最大字号的控件不相互覆盖。
- 分段流式软换行在完成前扩大输出框与原生窗口；大字号和窄窗口重测后无文字截断。
- 大小写修正不出现 edit 计数或卡片；连续翻译只发送当前原文，原文中的后续语言指令不改变下一轮输出语言。
- 开关有焦点时 Return 只发起一次当前模式请求，不误切换；Space 与切换后的输入焦点正常。
- 两套主题在逐帧切换中，运行按钮（含悬停）、模式胶囊、edit 展开按钮、纠正标签、模型文字和选中 Tab 的文字对比度至少 4.5:1。
- Tab 内边距与两种模式彩色胶囊，浅色和深色主题均检查。

测试使用假密钥和本地协议夹具，不读取用户真实密钥，也不产生付费模型调用。报告与截图由 `tests/e2e.mjs` 输出到被 Git 忽略的 `work/e2e/`。

本次另在独立临时数据目录的打包版中使用用户已配置的 DeepSeek 完成四条真实请求：生硬英文的局部改写、仅大小写修正、含语言指令的中文翻译，以及之后的独立中文翻译。公开 GIF 录制其中一条 Tune 和一条 Translate，保留流式输出与自动增高过程。临时目录关闭历史与总结，不修改个人配置或历史；未录制密钥页面。这四条功能样例不替代完整语言质量评测。

## 后续路线图与明确限制

- 实际模型语言质量仍需在配置真实 key 后独立评测，包含至少 30 条固定样本；目前协议测试不替代语言评测。
- macOS Apple Silicon 为本次实机验证平台。Windows 构建有 CI，安装使用及快捷键尚需实机验证；Intel macOS 尚未实机验证。
- macOS 包在生成安装包前进行 ad-hoc 签名与完整性校验，尚无 Developer ID 签名或公证；无自动更新。发布后从 Releases 手动更新。
- 输入法组合输入 Enter 有代码防护；候选窗、多屏拔插、全屏应用空间和非 QWERTY 键盘仍需交互实测。
- 总结发送有界的完整纠错片段，最大约 24,000 字符；超预算的改动不发送。后续可增加可恢复分块合并。
- 模型层未实现 OAuth、任意认证 header、环境变量凭据、备用供应商自动切换、Gemini 原生协议和多模态。
- 当前按调用次数限制后台总结，不提供价格估算或 token/费用硬预算；HTTP 重试可能产生额外前台费用。
- 历史界面检索显示最近 200 条匹配记录，JSON 导出包含全部记录；单个习惯最多展开 1,000 条来源。
- 历史导出支持 JSON；CSV 导出、自动备份和更复杂 schema 迁移留待后续版本。
- 开发工具依赖的审计报告存在 sprintf-js 的中等级拒绝服务警报，来自打包工具日志依赖；发布应用运行时依赖审计为零漏洞。当前不通过降级打包工具强行消除报告。
